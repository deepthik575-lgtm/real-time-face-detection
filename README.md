# Real-Time Face Detection System

A computer vision application built with Python and OpenCV that performs real-time face detection using Haar Cascade classifiers via webcam input.

## Features
- Real-time video frame processing from webcam
- Multi-scale spatial coordinate tracking
- Bounding-box visualization for detected faces

## Tech Stack
- Python
- OpenCV (`cv2`)
- Haar Cascade XML Classifiers

## How to Run

git clone https://github.com/deepthik575-lgtm/real-time-face-detection.git
   cd real-time-face-detection
